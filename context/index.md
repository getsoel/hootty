# Context index

IMPORTANT: Before any task, scan the entries below. If any "Use when" matches what you're about to do, read that file first. When in doubt, read it.

- `context/architecture.md` - Use when: navigating Sources/, tracing data flow, or locating a file by responsibility
- `context/swift-patterns.md` - Use when: writing or editing any Swift code (@Observable, Codable, SPM, MainActor gotchas)
- `context/swiftui.md` - Use when: working in Sources/Hootty/Views/ or HoottyApp.swift (layout, cursors, gestures, icons, hidden title bar, NSViewRepresentable pitfalls)
- `context/ghostty.md` - Use when: working in Sources/Hootty/Terminal/ or Sources/CGhostty/ (ghostty_surface_t / ghostty_app_t, callbacks, clipboard, key handling)
- `context/design.md` - Use when: creating or modifying UI components, working with design tokens, spacing, or theme colors
- `context/commands.md` - Use when: adding commands, modifying keyboard shortcuts, or working on CommandRegistry / command palette
- `context/testing.md` - Use when: writing tests, modifying Sources/HoottyCore/, or working in Tests/HoottyCoreTests/
